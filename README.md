# Personal Journal Manager
## Project Description
Personal Journal Manager is a simple Python project that allows users to manage their personal journal entries using file handling.
Users can add, view, search, and delete journal entries. All entries are stored in a text file named `journal.txt`.
## Features
1. **Add a New Entry** - Add a new journal entry with the current date and time.
2. **View All Entries** - Display all saved journal entries.
3. **Search for an Entry** - Search entries using a keyword or date.
4. **Delete All Entries** - Delete all journal entries after confirmation.
5. **Exit** - Exit the application.
## Technologies Used
- Python
- File Handling
- OOP (Object-Oriented Programming)
- Exception Handling
- `os` Module
- `datetime` Module
